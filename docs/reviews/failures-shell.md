# Failure audit — shell and account (2026-09-13)

Read-only. Nothing was built, run or tested; every claim below is from reading the code, and the Confidence column says how sure the reading is. Line numbers are as of commit 1f118cd.

## Done well

- `AppError` family → screen: `FailureState` (FailureState.swift:11-76) and `APIError.userFacingMessage` (APIError.swift:74-119) never show raw JSON, status codes or a stack; the API's own `message` is shown only for non-auth errors, which the API documents as safe.
- Token check is three-valued (TokenStore.swift:86-96, TokenStatus.swift:10-24) and only a real 401/403 clears the Keychain (SettingsView.swift:203-212). An offline check keeps the token.
- Account change forgets the profile id, taste ledger, library cache, blend exclusion, reminders, schedule build and Spotlight index in one place (RootView+Session.swift:112-130) — only the on-screen model is missing (see table).
- Content opt-in is confirmed with the actual consequence in plain words (SettingsView.swift:63-78, :146-152); turning it off is not.
- History clear is confirmed and says what survives (HistorySection.swift:44-60); the count is in the button label so the reader knows what they are erasing.
- Last format cannot be switched off, with a lock pill rather than a dimmed row (FormatSection.swift:46-58).
- Notification permission is asked only from the switch, never at launch, and "Open Settings" appears only after iOS has actually refused (RemindersSection.swift:35-51).
- Rate-limit gate refuses locally during a backoff and caps `Retry-After` at 15 minutes (RateLimitGate.swift:44-58, APIClient.swift:163-172); the countdown shown is the same capped number.
- Covers never show a broken-image glyph: BlurHash → flat colour, one retry, 404 not retried, failures never cached (CoverStore.swift:105-136, CoverImage.swift:65-88). `CoverImage` resets `loaded` before each fetch so a recycled card never shows the previous cover (CoverImage.swift:58-62).
- Onboarding is not a gate: Skip on every page, no covers required, no network required (OnboardingView.swift:3-17, :97-104).
- Toast never intercepts taps and announces to VoiceOver (Toast.swift:28, :60).
- Debug PAT cannot reach a Release build (Release.xcconfig:9, Debug.xcconfig `#include?`).
- Privacy manifest declares exactly what MangaBaka keeps and nothing else; `NetworkLedger`/`Signposts` are on-device only.
- Deep-link parsing rejects `/pages/N` and non-numeric paths without crashing (SeriesWebLink.swift:40-46).
